House Price Prediction Using Machine Learning

A machine learning project that predicts house values using California Housing dataset.

Project Overview

This project uses machine learning algorithms to estimate house values based on housing and location-related features.

Algorithms Used

- Linear Regression
- Random Forest Regression

Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Outlier detection
- Model training and evaluation
- Actual vs Predicted visualization
- Feature importance visualization
- Interactive Streamlit prediction dashboard

Dataset

California Housing dataset containing 20,640 records.

Note: This dataset is based on 1990 California census data. It is intended for machine learning practice and does not represent current individual-property prices.

Run the Project

Install dependencies:

pip install -r requirements.txt

Train the models:

python train_model.py

Run the web application:

streamlit run app.py
